# Evidence

This folder contains supporting evidence related to the investigation.

The original PCAP is not included in this public repository because of file size and because the source training exercise provides the original capture.

Evidence used during the investigation included:

- Wireshark packet captures
- Network endpoint and conversation statistics
- DNS and TLS observations
- Kerberos and SAMR evidence
- HTTP request/response data
- Extracted HTTP artifact metadata

All analysis was performed on the original training evidence in an isolated analysis environment.
